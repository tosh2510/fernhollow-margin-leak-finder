Subject: Something I built: a mini operating layer

Hi Pranay,

You asked to see something I've built with AI. This is a miniature operating layer for a fictional DTC apparel brand, Fernhollow. I built it in an afternoon with Claude Code. The data is synthetic and I planted six margin leaks in it.

It mirrors Shopify, QuickBooks, 3PL and inventory tables into one model. Margin tools are deterministic, so no number comes from the LLM. An agent reasons through those tools and argues against itself before proposing anything. For example, a $28 tee tops the loss list, and the agent keeps it: its loss is the $50 free-shipping threshold acting on tee pairs. Every write is approval-gated, every step is in a full trace, and rejections become policy rules.
